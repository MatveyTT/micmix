# Как продолжить проект в Claude Code

Весь контекст лежит в `CLAUDE.md`: Claude Code читает его сам при запуске в этой папке.
Объяснять заново ничего не нужно.

## 1. Установить Claude Code (один раз)

Открой **PowerShell** (обычный, без прав администратора) и выполни:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Закрой окно, открой новое и проверь: `claude --version` должен вывести номер версии.

Желательно поставить ещё [Git for Windows](https://git-scm.com/downloads/win): он пригодится
для GitHub и для работы Claude Code.

## 2. Запустить в папке проекта

```powershell
cd "$env:USERPROFILE\Downloads\micmix-apo\micmix-apo"
claude
```

При первом запуске откроется браузер для входа в аккаунт Claude.

## 3. Первое сообщение

Скопируй и отправь:

> Прочитай CLAUDE.md. Собери новую версию с журналом, поставь APO на встроенный микрофон,
> я запишу 5 секунд в «Звукозаписи», а потом разбери журнал и найди, почему нет бипа.

Окна «Разрешить этому приложению вносить изменения?» подтверждаешь ты сам: это права
администратора для установщика. Claude Code будет спрашивать разрешение на команды: читай,
что он собирается запустить, и разрешай.
