# Расширение MicMix для браузера

Транслирует звук **одной вкладки** в микрофон через приложение MicMix
(без расширения можно транслировать только весь браузер целиком).

## Установка (Chrome, Яндекс Браузер, Edge)

1. Открой `chrome://extensions` (в Яндексе — `browser://extensions`, в Edge — `edge://extensions`).
2. Включи **«Режим разработчика»**.
3. **«Загрузить распакованное расширение»** → выбери эту папку (`extension`).
   В приложении MicMix её открывает кнопка на вкладке «Источники» → «Добавить» → «Вкладка браузера».
4. Закрепи значок MicMix на панели.

## Как пользоваться

1. В MicMix добавь источник **«Вкладка браузера»**.
2. На нужной вкладке щёлкни значок MicMix: появится зелёная метка **ON** — звук вкладки идёт в микрофон.
   Ты его тоже слышишь, как обычно.
3. Ещё щелчок — остановить. Транслируется одна вкладка за раз.

Расширение подключается только к MicMix на этом компьютере (`ws://127.0.0.1:47823`) и никуда больше
ничего не отправляет. Приложение, в свою очередь, принимает звук только от расширений, а не от сайтов.
