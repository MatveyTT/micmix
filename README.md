# MicMix — звук приложений прямо в микрофон

Транслирует звук браузера, плеера или игры и звуки-кнопки прямо в микрофон, как Soundpad:
собеседники в Discord и играх слышат их вместе с твоим голосом, а в самих программах ничего
перенастраивать не нужно.

**Скачать:** [страница релизов](https://github.com/MatveyTT/micmix/releases) — установщик и расширение для браузера.

- **приложения:** несколько сразу, у каждого своя громкость, кнопка и горячая клавиша вкл/выкл;
  запоминаются по имени — закрыл и открыл браузер, звук снова пойдёт сам;
- **отдельная вкладка браузера** через расширение MicMix (`extension/`);
- **звуки как в Soundpad:** mp3, wav, ogg, flac, m4a — перетащи в окно, назначь каждому клавишу;
  «Стоп», общая громкость звуков, «Слышать самому» в наушниках;
- **горячие клавиши на всё:** весь звук в микрофон (по умолчанию **Ctrl+Alt+M**), все приложения,
  каждое приложение, каждый звук, остановить звуки;
- общая громкость, лимитер (без хрипа на громких местах), индикаторы уровня, трей;
- установка на любой микрофон в один клик, снятие с восстановлением настроек.

## Как это устроено

```
приложения ──WASAPI process loopback──┐
вкладка ──расширение → WebSocket──────┼─► движок (Rust): микшер, громкости, лимитер
звуки-кнопки (файлы) ─────────────────┘          │ общая память Global\MicMixApo.Ring.v1
                                                  ▼
микрофон ──► APO-эффект в audiodg.exe (C++) ── подмешивает звук ──► Discord, игры, запись
```

- `src/` — **APO** (Audio Processing Object): DLL, которую Windows загружает как эффект микрофона.
- `engine/` — **ядро** на Rust: захват приложений, звуки, микшер, приём вкладки; консольная утилита `micmix-engine`.
- `app/` — **приложение** на Tauri 2 + Svelte 5 + Tailwind 4.
- `extension/` — **расширение** для Chrome / Яндекс Браузера / Edge (Manifest V3), см. его README.
- `install-apo.ps1` — установка APO на микрофон (приложение вызывает его само).
- `.github/workflows/release.yml` — по тегу `v*` GitHub собирает установщик и публикует релиз.

## Что нужно

- Windows 10 2004+ или Windows 11, где снимается защита аудиодвижка
  (`DisableProtectedAudioDG = 1`: на 23H2 (22631) работает, на 25H2 уже нет — там нужна подпись)
- для сборки: Visual Studio 2026 с C++, [Rust](https://www.rust-lang.org/tools/install) (stable, MSVC),
  [Node.js](https://nodejs.org/) 20+

## Сборка и запуск

```bat
build.bat                      :: APO → build\MicMixApo.dll (и тест build\captest.exe)
cd app
npm install
npm run tauri dev              :: приложение в режиме разработки
npm run tauri build            :: установщик → target\release\bundle\nsis\
```

В приложении: вкладка **«Микрофон»** → «Установить» на нужном микрофоне (Windows спросит права
администратора) → вкладка **«Приложения»** → «Добавить приложение», вкладка **«Звуки»** → перетащи
файлы. Проверить можно кнопкой **«Тестовый бип»** и записью в «Звукозаписи» Windows.

Горячую клавишу назначают щелчком по полю «Клавиша» и нажатием сочетания. Можно Ctrl/Alt/Shift + буква,
цифра или F-клавиша, а F1–F11 и цифры цифрового блока — и без модификаторов. F12 Windows программам
не отдаёт. Если клавиша занята другой программой (например, Discord), MicMix покажет это рядом с ней.

Новый релиз: `git tag v0.3.1 && git push --tags` — остальное сделает GitHub Actions.

Без запущенного MicMix эффект ничего не подмешивает — микрофон работает как обычно.

## Консольная утилита

```bat
target\release\micmix-engine.exe apps                 :: приложения со звуком
target\release\micmix-engine.exe mics                 :: микрофоны и где стоит APO
target\release\micmix-engine.exe tone                 :: тестовый бип в микрофон
target\release\micmix-engine.exe capture chrome.exe   :: звук приложения в микрофон
target\release\micmix-engine.exe play звук.mp3        :: звук из файла в микрофон
build\captest.exe "Набор" default                     :: есть ли бип в микрофоне (без записи на слух)
```

## Установщик APO вручную

| Команда | Что делает |
|---|---|
| `install.bat` | выбрать микрофон из списка и поставить APO |
| `install.bat -Device HyperX` | поставить на микрофон, в имени которого есть «HyperX» |
| `install.bat -Status` | где стоит APO и загружен ли он |
| `install.bat -Uninstall` | снять с микрофона и вернуть исходные настройки |
| `install-apo.ps1 -EndpointId {guid} -Quiet` | без вопросов, с кодом возврата (так вызывает приложение) |

## Что делает скрипт

- Копирует DLL в `C:\Program Files\MicMixApo\` и регистрирует её как COM-объект.
- В настройках выбранного микрофона (`MMDevices\Audio\Capture\{id}\FxProperties`)
  ставит наш APO **первым** в цепочку эффектов. Эффекты драйвера (Realtek и т. п.) остаются после него.
- Включает «Улучшения звука» для этого микрофона, иначе Windows пропускает эффекты.
- Исходные значения сохраняет в `C:\ProgramData\MicMixApo\{id}.json`, и `-Uninstall` возвращает их.
- Если у администратора нет прав на ключ микрофона, скрипт берёт его во владение
  и выдаёт Администраторам полный доступ. При удалении права **не** откатываются.

## Если что-то пошло не так

- **Бипа нет, `-Status` пишет «нет доступа к процессу»:** защита аудиодвижка включена.
  Проверь ключ `DisableProtectedAudioDG` и перезагрузись.
- **Бипа нет, DLL не загружена:** некоторые программы открывают микрофон в «сыром» режиме
  (RAW) и обходят эффекты. Проверь через «Звукозапись» Windows.
- **Микрофон перестал работать:** `install.bat -Uninstall`, выбрать этот микрофон.
  Если и это не помогло, отключи «Улучшения звука» в свойствах микрофона
  (Параметры → Система → Звук → микрофон).
