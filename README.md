# MicMix — звук приложений прямо в микрофон (этап 1)

Транслирует звук выбранного приложения (браузера, плеера, игры) прямо в микрофон,
как Soundpad: в Discord и играх ничего перенастраивать не нужно.

Из чего состоит:
- **APO** (`src/`) — DLL, которая встраивается в аудиодвижок Windows как эффект микрофона
  и подмешивает в него звук из общей памяти;
- **движок** (`engine/`, Rust) — захватывает звук приложения и пишет его в общую память.

## Что нужно

- Windows 10 2004+ или Windows 11, где снимается защита аудиодвижка
  (`DisableProtectedAudioDG = 1`: на 23H2 (22631) защита снимается, на 25H2 уже нет)
- Visual Studio 2026 с нагрузкой «Разработка классических приложений на C++»
- [Rust](https://www.rust-lang.org/tools/install) (stable, MSVC)

## Как запустить

1. **Собрать APO:** дважды кликнуть `build.bat` → появятся `build\MicMixApo.dll` и `build\captest.exe`.
2. **Собрать движок:** в папке `engine` выполнить `cargo build --release`.
3. **Поставить APO:** дважды кликнуть `install.bat` → согласиться на запрос администратора →
   выбрать номер микрофона из списка. Для первого теста бери **встроенный** микрофон.
4. **Проверить бипом:** запустить `engine\target\release\micmix-engine.exe tone`, открыть
   «Звукозапись» Windows (или Discord → «Проверка микрофона») и записать пару секунд —
   должен быть слышен бип раз в секунду.
5. **Транслировать приложение:** `micmix-engine.exe capture chrome.exe` (или PID процесса).
   Громкость: `--gain 0.3`. Остановить — Ctrl+C.

Без движка APO ничего не подмешивает, микрофон работает как обычно.
Проверить без записи на слух: `build\captest.exe "Набор" default` (часть имени микрофона).

## Команды

| Команда | Что делает |
|---|---|
| `install.bat` | выбрать микрофон из списка и поставить APO |
| `install.bat -Device HyperX` | поставить на микрофон, в имени которого есть «HyperX» |
| `install.bat -Status` | где стоит APO и загружен ли он |
| `install.bat -Uninstall` | снять с микрофона и вернуть исходные настройки |

## Что делает скрипт

- Копирует DLL в `C:\Program Files\MicMixApo\` и регистрирует её как COM-объект.
- В настройках выбранного микрофона (`MMDevices\Audio\Capture\{id}\FxProperties`)
  ставит наш APO **первым** в цепочку эффектов. Эффекты драйвера (Realtek и т. п.) остаются после него.
- Включает «Улучшения звука» для этого микрофона, иначе Windows пропускает эффекты.
- Исходные значения сохраняет в `C:\ProgramData\MicMixApo\{id}.json`, и `-Uninstall` возвращает их.
- Если у администратора нет прав на ключ микрофона, скрипт берёт его во владение
  и выдаёт Администраторам полный доступ. При удалении права **не** откатываются.

## Если что-то пошло не так

- **Бипа нет, `-Status` пишет «нет доступа к процессу»:** защита аудиодвижка включена.
  Проверь ключ `DisableProtectedAudioDG` и перезагрузись.
- **Бипа нет, DLL не загружена:** некоторые программы открывают микрофон в «сыром» режиме
  (RAW) и обходят эффекты. Проверь через «Звукозапись» Windows.
- **Микрофон перестал работать:** `install.bat -Uninstall`, выбрать этот микрофон.
  Если и это не помогло, отключи «Улучшения звука» в свойствах микрофона
  (Параметры → Система → Звук → микрофон).
