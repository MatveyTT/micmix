# MicMix — звук приложений прямо в микрофон

MicMix подмешивает в микрофон звук браузера, плеера или игры и звуки-кнопки, как Soundpad.
Собеседники в Discord и играх слышат всё это вместе с твоим голосом, а в самих программах
ничего перенастраивать не нужно.

**Скачать:** [страница релизов](https://github.com/MatveyTT/micmix/releases), там установщик и расширение для браузера.

Что умеет:

- Несколько приложений сразу, у каждого своя громкость, кнопка и горячая клавиша вкл/выкл.
  Приложение запоминается по имени: закрыл браузер, открыл снова, и звук опять пойдёт сам.
- Отдельная вкладка браузера через расширение MicMix (`extension/`).
- Звуки как в Soundpad: mp3, wav, ogg, flac, m4a. Перетаскиваешь файлы в окно и назначаешь каждому
  клавишу. Есть «Стоп», общая громкость звуков и «Слышать самому» в наушниках.
- Горячие клавиши на всё: весь звук в микрофон (по умолчанию **Ctrl+Alt+M**), все приложения,
  каждое приложение, каждый звук, остановить звуки.
- Общая громкость, лимитер (чтобы громкие места не хрипели), индикаторы уровня, трей.
- Установка на любой микрофон в один клик; при снятии настройки микрофона возвращаются.

## Как это устроено

```
приложения ──WASAPI process loopback──┐
вкладка ──расширение → WebSocket──────┼─► движок (Rust): микшер, громкости, лимитер
звуки-кнопки (файлы) ─────────────────┘          │ общая память Global\MicMixApo.Ring.v1
                                                  ▼
микрофон ──► APO-эффект в audiodg.exe (C++) ── подмешивает звук ──► Discord, игры, запись
```

- `src/` — APO (Audio Processing Object): DLL, которую Windows загружает как эффект микрофона.
- `engine/` — ядро на Rust: захват приложений, звуки, микшер, приём вкладки. Там же консольная утилита `micmix-engine`.
- `app/` — само приложение на Tauri 2 + Svelte 5 + Tailwind 4.
- `extension/` — расширение для Chrome / Яндекс Браузера / Edge (Manifest V3), у него свой README.
- `install-apo.ps1` ставит APO на микрофон. Приложение вызывает его само.
- `.github/workflows/release.yml`: по тегу `v*` GitHub собирает установщик и публикует релиз.

## Что нужно

- Windows 10 2004+ или Windows 11, где снимается защита аудиодвижка
  (`DisableProtectedAudioDG = 1`, MicMix включает его сам). Проверено на 23H2 (22631) и 25H2 (26200):
  подпись Microsoft не нужна.
- Для сборки: Visual Studio 2026 с C++, [Rust](https://www.rust-lang.org/tools/install) (stable, MSVC),
  [Node.js](https://nodejs.org/) 20+.

## Какие микрофоны подходят

MicMix ставится на любой микрофон из списка во вкладке «Микрофон». Проверено на встроенном микрофоне
ноутбука (Intel Smart Sound) и на USB-микрофоне HyperX SoloCast, в том числе на обоих одновременно.

- USB-микрофоны на стандартном драйвере Windows работают начиная с версии 0.3.2. Если ставил MicMix
  на такой микрофон раньше и звука не было, нажми «Установить» на нём ещё раз.
- Частота микрофона может быть любой (44,1, 48, 96 кГц): MicMix берёт её у самого микрофона.
- **Нюанс с несколькими микрофонами.** Все микрофоны с MicMix берут звук из одной общей памяти в одной
  частоте. Если MicMix стоит на двух микрофонах с разной частотой и с обоих пишут одновременно
  (например, Discord с одного, OBS с другого), звук приложений попадёт только в один из них.
  Когда пишут с одного микрофона за раз, всё работает: MicMix сам переключается на частоту того,
  с которого начали запись, и при переключении может быть короткий щелчок. Проще всего ставить MicMix
  только на тот микрофон, которым пользуешься, а на остальных нажать «Снять».
- Не заработает, если Microsoft в будущем запретит неподписанные эффекты (пока на 25H2 работает), на микрофонах,
  драйвер которых не пускает системные эффекты (часть гарнитур со своей программой, Bluetooth-гарнитуры
  в режиме «головной телефон»), и в программах, которые открывают микрофон в режиме RAW.

## Сборка и запуск

```bat
build.bat                      :: APO → build\MicMixApo.dll (и тест build\captest.exe)
cd app
npm install
npm run tauri dev              :: приложение в режиме разработки
npm run tauri build            :: установщик → target\release\bundle\nsis\
```

Дальше в приложении: вкладка **«Микрофон»** → «Установить» на нужном микрофоне (Windows спросит права
администратора), потом вкладка **«Приложения»** → «Добавить приложение» и вкладка **«Звуки»**, куда
перетаскиваешь файлы. Проверить можно кнопкой **«Тестовый бип»** и записью в «Звукозаписи» Windows.

Чтобы назначить горячую клавишу, щёлкни по полю «Клавиша» и нажми сочетание. Подойдут Ctrl/Alt/Shift
с буквой, цифрой или F-клавишей, а F1–F11 и цифры цифрового блока можно и без модификаторов. F12 Windows
программам не отдаёт. Если клавишу уже заняла другая программа (например, Discord), MicMix покажет это рядом с ней.

Новый релиз: подними версию в `app/package.json`, `app/src-tauri/tauri.conf.json` и `Cargo.toml`,
потом `git tag v0.X.Y && git push origin v0.X.Y`. Остальное сделает GitHub Actions.

Пока MicMix не запущен, эффект ничего не подмешивает и микрофон работает как обычно.

## Консольная утилита

```bat
target\release\micmix-engine.exe apps                 :: приложения со звуком
target\release\micmix-engine.exe mics                 :: микрофоны и где стоит APO
target\release\micmix-engine.exe tone                 :: тестовый бип в микрофон
target\release\micmix-engine.exe capture chrome.exe   :: звук приложения в микрофон
target\release\micmix-engine.exe play звук.mp3        :: звук из файла в микрофон
build\captest.exe "Набор" default                     :: есть ли бип в микрофоне (без записи на слух)
```

## Установщик APO вручную

| Команда | Что делает |
|---|---|
| `install.bat` | выбрать микрофон из списка и поставить APO |
| `install.bat -Device HyperX` | поставить на микрофон, в имени которого есть «HyperX» |
| `install.bat -Status` | где стоит APO и загружен ли он |
| `install.bat -Uninstall` | снять с микрофона и вернуть исходные настройки |
| `install-apo.ps1 -EndpointId {guid} -Quiet` | без вопросов, с кодом возврата (так вызывает приложение) |

## Что делает скрипт

- Копирует DLL в `C:\Program Files\MicMixApo\` и регистрирует её как COM-объект.
- В настройках выбранного микрофона (`MMDevices\Audio\Capture\{id}\FxProperties`)
  ставит наш APO первым в цепочку эффектов. Эффекты драйвера (Realtek и т. п.) остаются после него.
- Если у микрофона нет своих эффектов (так бывает у USB-микрофонов), прописывает привязку эффекта
  к устройству и режим обработки DEFAULT. Без них Windows молча не подключает эффект к записи.
- Включает «Улучшения звука» для этого микрофона, иначе Windows пропускает эффекты.
- Исходные значения сохраняет в `C:\ProgramData\MicMixApo\{id}.json`, и `-Uninstall` их возвращает.
- Если у администратора нет прав на ключ микрофона, скрипт берёт ключ во владение
  и выдаёт Администраторам полный доступ. При удалении права **не** откатываются.

## Если что-то пошло не так

- **Бипа нет, а `-Status` пишет «нет доступа к процессу».** Включена защита аудиодвижка.
  Проверь ключ `DisableProtectedAudioDG` и перезагрузись.
- **Бипа нет, DLL не загружена.** Некоторые программы открывают микрофон в «сыром» режиме (RAW)
  и обходят эффекты. Проверь через «Звукозапись» Windows.
- **На одном микрофоне звук есть, на другом нет.** Проверь, что частота у них одинаковая
  (Параметры → Система → Звук → микрофон → Формат), или оставь MicMix только на одном.
- **Что-то сломалось.** Загляни в журнал ошибок приложения: `%APPDATA%\MicMix\micmix.log`.
- **Микрофон перестал работать.** Запусти `install.bat -Uninstall` и выбери этот микрофон.
  Если не помогло, отключи «Улучшения звука» в свойствах микрофона
  (Параметры → Система → Звук → микрофон).
