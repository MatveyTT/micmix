# MicMix — план проекта

## Идея

Программа для Windows, которая транслирует звук выбранной вкладки браузера, всего браузера или
выбранных приложений в микрофон, по аналогии с Soundpad. Отличия: звук берётся сразу из
приложений, а интерфейс современный и красивый. Первый проект для GitHub.

## Ключевые технические решения

| Задача | Решение | Почему |
|---|---|---|
| Звук отдельного приложения | WASAPI process loopback (`AUDIOCLIENT_PROCESS_LOOPBACK`) | захватывает процесс вместе с дочерними процессами, драйвер не нужен; Win10 2004+ / офиц. 20348+ |
| Весь браузер | тот же loopback по PID корневого процесса браузера | у Chrome все вкладки звучат через один процесс |
| Отдельная вкладка | расширение Chrome/Edge MV3: `tabCapture` + offscreen-документ → PCM по WebSocket на localhost | иначе вкладку из общего процесса браузера не выделить |
| Доставка в микрофон (основной режим) | свой APO в цепочке эффектов выбранного микрофона | как Soundpad: в играх и Discord ничего настраивать не нужно |
| Доставка (запасной режим) | виртуальный кабель VB-CABLE / VAC Lite (подписанный драйвер) | работает везде, в том числе на Windows 11 25H2+ без подписи APO |
| Приложение | Tauri 2 + Rust, фронт Svelte 5/React + Tailwind 4 | лёгкое, современный интерфейс, Rust подходит для аудио в реальном времени |
| Связь движка и APO | общая память (кольцевой буфер float32) + событие | без блокировок, минимальная задержка |

Ограничения:
- Неподписанный APO работает только при `DisableProtectedAudioDG = 1`. На Win11 25H2 этот ключ не действует.
- Программы, которые открывают микрофон в RAW или эксклюзивном режиме, обходят эффекты.
- Голосовые чаты сильно сжимают звук, а шумодав в Discord/игре может резать музыку, его нужно отключать.

## Этапы

0. ✅ **Прототип APO**: DLL подмешивает тестовый бип в выбранный микрофон, есть универсальный установщик.
1. ✅ **Захват звука**: Rust-программа берёт звук процесса по PID и отдаёт его в APO через общую память.
   Несколько источников, микшер (громкость и mute для каждого), лимитер, прослушивание звуков в наушниках.
2. ✅ **Интерфейс** на Tauri (базовая версия): карточки источников с иконками приложений, индикаторы уровня, трей,
   горячие клавиши (на каждое приложение, звук и общие действия), тёмная тема. Пока нет: несколько пресетов.
3. ✅ **Расширение для вкладок**: Chrome/Edge MV3.
4. **Режим без APO**: вывод в виртуальный кабель, мастер первого запуска.
5. ✅ **Релиз на GitHub** (сборка по тегу, установщик NSIS; пока без автообновления и GIF): установщик (MSI/NSIS), GitHub Actions, README с GIF-демо, автообновление.
6. **Бонусы**: ✅ кнопки звуков как в Soundpad; шумоподавление, Linux через PipeWire.
